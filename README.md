# odin-recipes

Objectives
1) Create a homepage for a recipe book with a minimum of 3 recipes
2) Each recipe must link to a standalone page with the recipe

Learning objectives
- Set up a fundamental home and recipe pages with the following HTML elements: <p> <a> <h1> <img>

Roadmap
1) Set up the homepage with boilerplate
2) In a new directory, set up the 3 pages for the recipes
3) Include the following 4 elements in your page: image of the dish, description of the recipe, ingredients in an unordered list, steps in an ordered list
4) Submit to GitHub
